# 校园网一键登录 · 界面改版交付说明（给开发 AI）

> 使用方式：把整个 `交付素材` 文件夹整个复制到项目里（建议路径 `项目/assets/design/`），
> 然后把 **本文件 + `设计稿-主界面.png`** 一起交给开发 AI，并复制第三节的提示词。
> **规范优先级：本文件的数值 > 设计稿 PNG**（AI 看图标容易估错像素，看数值才准）。

---

## 一、文件清单

| 文件 | 类型 | 规格 | 用途 |
|---|---|---|---|
| `设计稿-主界面.png` | PNG | 2120×1560（2x） | 视觉基准，给 AI / 开发看终稿效果 |
| `应用图标-1024.png` | PNG | 1024×1024 | 应用主图标源图 |
| `app-icon.ico` | ICO | 16/32/48/64/128/256 | **Windows 窗体图标 + 任务栏图标** |
| `app-icon-16/32/48/64/128/256.png` | PNG | 各尺寸 | 安装包、快捷方式、高分屏适配 |
| `空态插画-未连接-1024.png` | PNG | 1024×1024 | 未连接 / 登录失败页的空态插画 |
| `icon-wifi / user / lock / eye / power / refresh / shield / clock.svg` | SVG | 24×24 矢量 | 界面图标，**务必用 SVG，不要用 emoji/字符替代** |

图标均为矢量，`fill/stroke` 颜色需在用时改成 `currentColor` 或对应状态色，便于主题统一。

---

## 二、三步交付流程

1. 复制 `交付素材` 文件夹 → 项目 `assets/design/`（或你习惯的资源目录）。
2. 把 `设计稿-主界面.png` 拖进开发 AI 对话框，同时让它读取 `README-给开发AI.md`。
3. 复制下方提示词发送。

---

## 三、可直接复制给开发 AI 的提示词

```
请你作为 Windows 桌面应用开发工程师，按照交付的设计稿与规范，重构「校园网一键登录」主界面。

输入文件（已放在项目 assets/design/ 下）：
- 设计稿-主界面.png：视觉基准
- README-给开发AI.md：尺寸、色值、字号、间距规范，实现时以该文件数值为准
- icon-*.svg：8 个矢量界面图标
- app-icon.ico：窗体与任务栏图标

要求：
1. 窗口尺寸 1060×780，需适配 Windows DPI 缩放（125%/150%）。
2. 严格按 README 中的色板、字号、圆角、间距实现，不要凭截图目测估数值。
3. 保留现有全部功能：账号、密码（可显示/隐藏）、运营商选择、保存并立即登录、
   启动/停止后台保活、开机自启。运营商下拉框改为 4 个分段按钮。
4. 新增：左侧导航栏、顶部渐变状态主卡（IP / 运营商 / 在线时长 / 今日流量）、
   运行日志卡、维护卡（检查更新、打开日志目录）、应用图标、未连接空态页。
5. 图标一律使用提供的 SVG，按 currentColor 着色；禁止用 emoji、◯/✓ 等字符充当图标。
6. 输出前先列出：要改动的文件清单 + 组件拆分方案 + 实现计划，我确认后再写代码。
```

## 四、设计规范（Design Spec）

### 4.1 窗口与骨架

| 项 | 值 |
|---|---|
| 窗口尺寸 | 1060 × 780 px |
| 标题栏高度 | 44 px，深蓝渐变 `#014DB2 → #001645`，左右内边距 14 |
| 侧边栏宽度 | 200 px，白底，右侧 1px `#E5E7EB` 分隔线 |
| 内容区 | 内边距 24，卡片间距 16，底色 `#F9F9F9` |
| 卡片 | 内边距 20，圆角 12，白底 `#FFFFFF`，描边 1px `#EAEAEA`，阴影 `0 2px 8px rgba(16,26,40,0.05)` |

### 4.2 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 / 品牌蓝 | `#014DB2` | 主按钮、选中态、导航选中底 |
| 深蓝 | `#001645` | 标题栏与渐变末端 |
| 渐变主按钮 | `#0059C7 → #003B99` | 「保存并立即登录」 |
| 成功绿 | `#10B981` | 在线状态、成功提示 |
| 警示黄 | `#F59E0B` | 网络波动类日志 |
| 错误红 | `#EF4444` | 停止保活按钮、失败态 |
| 浅蓝底 | `#E8F0FE` | 次级按钮、选中背景 |
| 浅蓝卡片底 | `#F0F6FF` | 侧边状态卡 |
| 成功浅底 | `#F0FDF4` | 状态提示行 |
| 中性底 | `#F3F4F6` | 快捷操作、维护按钮 |
| 画布底 | `#F9F9F9` | 内容区背景 |
| 主文字 | `#0A1628` | 标题、正文 |
| 次文字 | `#6B7280` | 字段标签、辅助说明 |
| 弱文字 / 占位 | `#9CA3AF` | 输入框图标、提示文字 |
| 描边 | `#EAEAEA` / `#D6D9DE` | 卡片边框 / 输入框边框 |

### 4.3 字体

- 中文：`Noto Sans SC`；桌面端回退建议 `Microsoft YaHei UI → PingFang SC → system-ui`
- 数字 / 英文：`Inter`（回退 `Segoe UI`）
- 日志时间与 IP 建议开启等宽数字（`tabular-nums`），避免跳动

| 层级 | 字号 / 字重 |
|---|---|
| 状态主卡标题 | 22 Bold |
| 卡片标题 | 16 SemiBold |
| 按钮（主） | 15 Medium |
| 正文 / 输入框值 | 14 Regular（数字用 Inter） |
| 按钮（次） / 标签 / 导航 | 13 Medium 或 Regular |
| 字段标签 / 日志 / 辅助说明 | 12 Regular |
| 分组标题 / 提示 | 11 Regular |
| 版本号 | 10 Regular |

### 4.4 组件规格

| 组件 | 规格 |
|---|---|
| 导航项 | 高 38，圆角 8，内边距 12，图标 16，图标与文字间距 10；选中：底 `#014DB2` + 白字；默认：透明底 + `#374151` |
| 输入框 | 高 40，圆角 8，白底，描边 `#D6D9DE`，内边距 12，前置图标 16 `#9CA3AF` |
| 分段按钮（运营商） | 高 34，圆角 8，间距 8，等宽；选中 `#014DB2` 底白字，默认白底灰边 |
| 主按钮 | 高 46，圆角 8，渐变 `#0059C7 → #003B99`，白字 15，图标 16，阴影 `0 4px 12px rgba(1,77,178,0.3)` |
| 次级按钮 | 高 38，圆角 8；启动保活 `#E8F0FE` 底 `#C6DAF8` 边蓝字；停止保活 `#FEF2F2` 底 `#FECACA` 边红字 |
| 开关 Toggle | 40 × 22，圆角 11，开 `#014DB2`，滑块 16 白，内边距 3 |
| 复选框 | 16 × 16，圆角 4，白底灰边；勾选后 `#014DB2` 底 + 白色对勾 |
| 状态 pill | 圆角 999（全圆），高约 28，成功 `#10B981` / 中性浅蓝 `#F0F6FF` + 蓝字 |
| 日志行 | 行高约 20，圆点 6px（成功绿 / 警示黄），文字 12 Inter |

### 4.5 需要新增的功能点（对照现有版本）

| # | 新增项 | 说明 |
|---|---|---|
| 1 | 左侧导航 | 连接状态 / 账号设置 / 保活设置 / 开机自启 / 运行日志 / 关于，选中态为蓝底圆角块 |
| 2 | 顶部状态主卡 | 渐变蓝卡：连接状态文案 + IP 地址 + 运营商 + 在线时长 + 今日流量 |
| 3 | 侧边实时状态小卡 | 显示「已连接 · 移动」与在线时长 |
| 4 | 快捷操作 | 刷新认证、断开连接（侧边栏内） |
| 5 | 运营商分段按钮 | 替换原有下拉框：移动 / 电信 / 联通 / 教育网 |
| 6 | 运行日志卡 | 彩色圆点区分成功与异常，支持「查看全部」跳转日志页 |
| 7 | 维护卡 | 检查更新、打开日志目录 |
| 8 | 未连接空态页 | 使用 `空态插画-未连接-1024.png` + 一句引导文案 + 「重新连接」按钮 |
| 9 | 应用图标 | 使用 `app-icon.ico`，同时替换任务栏与桌面快捷方式图标 |

### 4.6 状态与交互约定

| 状态 | 视觉表现 |
|---|---|
| 未登录 | 主卡灰蓝底 + 「未连接」文案 + 空态插画 + 主按钮「保存并立即登录」|
| 认证中 | 主按钮 Loading 态（禁用 + 转圈），主卡文案「正在认证…」|
| 已连接 | 主卡渐变蓝 + 绿色「在线」pill + 实时在线时长（每秒刷新）|
| 保活运行中 | 绿色状态行「后台保活运行中（PID xxxx）」+ 停止按钮可用 |
| 保活未启动 | 中性状态行，启动按钮高亮、停止按钮置灰禁用 |
| 掉线重连 | 警示黄日志条目 + 顶部黄色提示条 3 秒后自动消失 |

---

## 五、落地提醒

- 所有尺寸为设计稿 1x 值，请用矢量 / SVG 资源以适配高分屏，避免位图拉伸模糊。
- Windows 窗体若使用 WinForms，建议把卡片抽成 `UserControl`，卡片间间距统一走 `TableLayoutPanel` / `FlowLayoutPanel` 的 16px gap。
- 若后端暂未提供「今日流量」数据，可先隐藏该指标，保持主卡其余三项布局不变。
- 需要深色模式、更多状态插画（认证中 / 正在重连）可再追加素材。
